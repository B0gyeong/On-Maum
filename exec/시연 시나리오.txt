--------------------------------------------------------------
 0. 시연 전 준비
--------------------------------------------------------------
한 브라우저에는 한 역할만 로그인됩니다. 담당자와 대상자를 동시에 보여 주려면
서로 다른 브라우저 두 개를 씁니다. (시연 영상 기준: 왼쪽 Chrome = 담당자, 오른쪽 Edge = 대상자)

0-1. 담당자 화면 (Chrome, 화면 왼쪽 절반)
  1) https://j15d201.p.ssafy.io 접속
  2) 메인 화면 "이용하실 서비스를 선택해 주세요." 아래 왼쪽 카드 [복지담당자] 클릭
  3) "복지담당자 로그인" 화면
     - 이메일 칸에 manager01@nilm.local 입력
     - 비밀번호 칸에 NilmTest1234! 입력
     - (선택) [로그인 상태 유지] 체크
     - 주황색 [로그인하기] 버튼 클릭
  4) 대시보드가 열리면 오른쪽 위에 "연결됨"이 보이는지 확인
     ("연결 중" / "재연결 중"이면 실시간 알림이 오지 않으니 옆의 [새로고침] 클릭 또는 페이지 새로고침)

0-2. 대상자 화면 (Edge, 화면 오른쪽 절반. 창을 세로로 좁게 두면 휴대폰 화면처럼 보임)
  1) https://j15d201.p.ssafy.io 접속
  2) 메인 화면 오른쪽 카드 [복지대상자] 클릭
  3) "복지대상자 로그인" 화면
     - 이메일 칸에 subject01@nilm.local 입력
     - 비밀번호 칸에 NilmTest1234! 입력
     - 주황색 [로그인하기] 버튼 클릭
  4) 홈 화면 맨 아래쪽 "안심 알림" 카드 확인
     - "알림을 켜 주세요"가 보이면 [알림 켜기] 클릭 → 브라우저 알림 권한 팝업에서 [허용]
     - "안심 알림 켜져 있어요"로 바뀌면 준비 완료
       (이게 꺼져 있으면 4단계의 브라우저 푸시 알림이 오지 않음)
  5) (선택) "위치 서비스" 카드의 [위치 허용하기] 클릭 → 브라우저 위치 권한 [허용]
     → "켜져 있어요"로 바뀜
  6) 화면 맨 아래 고정 바가 "재실 중 / 집에 계신 상태예요"인지 확인
     ("외출 중"이면 가운데 위 주황 버튼 [집에 돌아왔어요]를 눌러 재실로 되돌림)

0-3. 시뮬레이터 화면 (담당자 Chrome에서 새 탭)
  1) https://j15d201.p.ssafy.io/simulator/routine-demo 접속
  2) 제목 "평소 쓰던 전자레인지를 오늘은 사용하지 않은 상황을 비교합니다" 화면이 뜨면 준비 완료

0-4. 재시연 전 초기화 확인
  - 담당자 대시보드에서 대상자 01의 "최근 알림 응답"에 [해결 완료] 버튼이 남아 있으면 먼저 눌러
    이전 도움 요청을 정리해 둔다.


--------------------------------------------------------------
 1. 시연 순서 (시연 영상 순서 기준)
--------------------------------------------------------------

[STEP 1] 평소 생활 패턴과 오늘 전력 사용 비교  - 시뮬레이터 화면
  화면 구성
    - 오른쪽 위 "표시 범위" 드롭다운: 2분 확대(기본) / 전체 구간
    - 01 평소 생활 패턴 (위쪽 그래프): 평소 전자레인지를 약 1분 쓰는 기록 파형(발표용 재생, 데이터 발행 안 함)
    - 02 금일 패턴 (아래쪽 그래프): 대상자 가구(H001)의 오늘 측정값 330개를 실제 MQTT로 발행
  조작
    1) 아래쪽 02 카드 하단의 "발행 속도" 드롭다운을 [5×]로 변경
    2) 바로 왼쪽의 [▶ 실시간 실행] 버튼 클릭
       → 버튼이 흐려지고 [■ 중지]가 활성화됨
       → 오른쪽 아래 "발행 N / 330" 숫자가 올라가고, 그래프에 대기전력(약 120W)만 그려짐
       → 음영(평소 사용 구간)에서도 전력이 올라가지 않음 = 평소 쓰던 전자레인지를 오늘은 안 씀
    3) (선택) 위쪽 01 카드의 [▶ 재생]을 눌러 평소 파형(약 1.2kW로 1분 사용)을 함께 보여 줌
       재생 속도 드롭다운으로 속도 조절, [↺ 처음부터]로 되감기
  설명 멘트
    "위는 평소 이 시간에 전자레인지를 1분 정도 쓰던 기록이고, 아래는 오늘 실제로 들어오는 전력입니다.
     오늘은 대기전력만 흐르고 있습니다. 이 데이터가 MQTT → Kafka → 실시간 분석 서비스로 흘러갑니다."
  ※ 발행은 멈추지 말고 그대로 둔 채 담당자 대시보드 탭으로 전환

[STEP 2] 담당자 대시보드 / 대상자 홈 화면 소개  - 두 브라우저를 좌우로 배치
  담당자 (왼쪽)
    - 왼쪽 사이드바: [대시보드] [대상자 관리] [최근 알림], 아래쪽에 담당자 01 정보와 [로그아웃]
    - 가운데 "대상자 현황": 담당 대상자 30명, 위험 / 주의 / 안정 인원 수
    - "등록 대상자" 표: 위험 점수가 높은 순으로 정렬(확인 순서), 전화번호·위험 단계·현재 위험 점수·최근 알림 응답·상세
  대상자 (오른쪽)
    - "안녕하세요 대상자 01님"
    - 주황색 큰 버튼 [외출하기]
    - "담당자 01" 카드와 [담당자에게 전화하기] 버튼
    - 위치 서비스 / 안심 알림 카드
    - 화면 맨 아래 고정 바: "재실 중 - 집에 계신 상태예요"

[STEP 3] 위험 감지 → 담당자 대시보드 실시간 알림  - 담당자 화면 (자동)
  발행이 이어지면 분석 서비스가 평소와 다른 사용을 판정하고, 새로고침 없이 담당자 화면에 알림이 뜬다.
    - 화면 가장자리가 빨갛게 두 번 깜빡임
    - "대시보드" 제목 아래 알림 배너:
        "대상자 01님 · 위험 신호가 감지되었습니다. 대상자에게 연락하여 안부를 확인해 주세요."
        오른쪽에 점수(예: 90점), 감지 시각, 검은 [상세보기] 버튼, [X] 닫기
    - "대상자 현황"의 위험 인원이 1명으로 바뀜
    - 등록 대상자 표 1번 줄 "대상자 01 · 76세"가 위험(빨강) / 90점 / 응답 대기로 바뀜
    - 오른쪽 아래 검은 토스트 "새 알림 - 위험 감지 1건 →" (클릭하면 알림 목록으로 스크롤)
  설명 멘트
    "담당자는 새로고침하지 않아도 SSE로 위험 알림을 바로 받습니다. 위험 점수가 높은 대상자가 맨 위로 올라옵니다."

[STEP 4] 대상자에게 안전 확인 요청  - 대상자 화면 (자동)
  위험 감지와 동시에 대상자에게 안부 확인이 간다.
    - 화면 오른쪽 아래에 브라우저(OS) 푸시 알림
        제목 "안전 확인 요청" + 감지 내용과 "현재 위험하신가요?"
        알림 안의 버튼 [도움이 필요해요] / [괜찮아요]
    - 대상자 화면이 어둡게 덮이고, 하단 고정 바가 올라오며
        "지금 상태를 알려주세요"  빨간 [도움이 필요해요]  흰색 [괜찮아요]
  설명 멘트
    "대상자는 앱을 열어 두지 않아도 푸시 알림에서 바로 응답할 수 있고, 화면에서도 큰 버튼 두 개로 답합니다."

[STEP 5] 도움 요청 → 담당자에게 즉시 전달
  조작 (대상자 화면)
    - 하단의 빨간 [도움이 필요해요] 버튼 클릭
      (또는 푸시 알림 안의 [도움이 필요해요] 클릭 - 대상자 화면이 열리며 같은 응답이 전송됨)
    → 대상자 화면 하단에 체크 애니메이션과 "도움 요청이 접수됐어요." 표시 후 다시 "재실 중"
  결과 (담당자 화면, 자동)
    - 기존 위험 배너 위에 빨간 배너가 추가됨
        "대상자 01님 · 도움을 요청했습니다. '도움이 필요해요' 응답을 보냈습니다. 바로 연락해 주세요."
        오른쪽에 빨간 [대상자 확인] 버튼
    - 등록 대상자 표의 대상자 01 이름 옆에 빨간 [도움 요청] 배지
      "최근 알림 응답" 칸이 "도움 요청"으로 바뀌고 [해결 완료] 버튼이 생김
    - 오른쪽 아래 토스트가 빨갛게 "새 알림 - 도움 요청 1건 · 위험 감지 1건 →"
  (참고) [괜찮아요]를 누르면 대상자 화면에 "괜찮다는 응답이 접수됐어요.",
         담당자 화면에 "괜찮다고 응답했습니다." 안전 응답 알림이 뜸
         응답하지 않고 시간이 지나면 담당자 화면에 "안부 확인 응답 시간이 지났습니다." 알림이 뜸

[STEP 6] 담당자 후속 조치 (영상 이후 추가 시연용)
  1) 빨간 배너의 [대상자 확인] (또는 위험 배너의 [상세보기]) 클릭
     → 대상자 상세 화면으로 이동, "알림 및 응답 이력"에서 해당 알림이 강조 표시됨
     → 상세 화면: 현재 상태(위험 점수, 상태 갱신), 연락 및 알림 응답(전화번호, 최근 응답, 응답 시각),
                  일별 위험 점수 추이(최근 7일 그래프), 알림 및 응답 이력
  2) 왼쪽 위 [← 대상자 목록]으로 돌아가 대상자 01 줄의 [해결 완료] 클릭
     → "최근 알림 응답"이 "해결 완료"로 바뀌고 도움 요청 배너가 사라짐
  3) 왼쪽 사이드바 [최근 알림] 클릭 → 위험 감지 / 도움 요청 내역이 최근 순으로 쌓여 있는 것 확인


--------------------------------------------------------------
 2. 대상자로 로그인해서 할 수 있는 기능  (subject01@nilm.local)
--------------------------------------------------------------
로그인 경로: 메인 → [복지대상자] → 이메일/비밀번호 입력 → [로그인하기]
화면 주소: https://j15d201.p.ssafy.io/user

2-1. 외출 / 귀가 알리기
  - 화면 위 주황색 큰 버튼 [외출하기] 클릭
    → 하단에 "외출 설정 완료", 하단 고정 바가 주황색 "외출 중 - 집 밖에 계신 상태예요"로 바뀜
    → 외출 중에는 전력 사용이 없어도 위험으로 보지 않도록 분석에 반영됨
  - 외출 중에는 같은 자리 버튼이 [집에 돌아왔어요]로 바뀜 → 클릭하면 "귀가 설정 완료", "재실 중"으로 복귀

2-2. 담당자에게 전화하기
  - "담당자 / 담당자 01" 카드의 [담당자에게 전화하기] 버튼
    → 휴대폰에서는 바로 전화 연결(tel: 링크), PC에서는 전화 앱 선택 창이 뜸

2-3. 위치 서비스 켜기
  - "위치 서비스" 카드의 [위치 허용하기] → 브라우저 위치 권한 허용 → "켜져 있어요"
  - 자동 외출/재실 판단에 쓰기 위한 권한. 거부했을 때는 [다시 확인하기]로 재시도

2-4. 안심 알림(푸시) 켜기
  - "안심 알림" 카드의 [알림 켜기] → 브라우저 알림 권한 허용 → "안심 알림 켜져 있어요"
  - 켜 두면 위험 감지 시 브라우저를 보고 있지 않아도 OS 푸시 알림으로 안전 확인 요청을 받음

2-5. 안전 확인 요청에 응답하기
  - 위험이 감지되면 화면 하단에 "지금 상태를 알려주세요"가 올라옴
      [도움이 필요해요] → 담당자에게 도움 요청 전달 ("도움 요청이 접수됐어요.")
      [괜찮아요]       → 담당자에게 안전 응답 전달 ("괜찮다는 응답이 접수됐어요.")
  - 푸시 알림 안의 같은 버튼으로도 응답 가능
  - 응답 시간이 지나면 "안부 확인 응답 시간이 지났어요." 안내 후 응답 창이 닫힘

2-6. 현재 상태 확인
  - 화면 맨 아래 고정 바: "재실 중"(흰색) / "외출 중"(주황색)

2-7. 계정 메뉴
  - 오른쪽 위 사람 아이콘 클릭 → [서비스 선택](메인으로) / [로그아웃](빨간 글씨)


--------------------------------------------------------------
 3. 담당자로 로그인해서 할 수 있는 기능  (manager01@nilm.local)
--------------------------------------------------------------
로그인 경로: 메인 → [복지담당자] → 이메일/비밀번호 입력 → [로그인하기]
화면 주소: https://j15d201.p.ssafy.io/staff

3-1. 대시보드 (왼쪽 사이드바 [대시보드])
  - 대상자 현황: 담당 대상자 수와 위험 / 주의 / 안정 인원
  - 실시간 알림 배너 (SSE, 새로고침 불필요)
      위험 감지(흰 배너, [상세보기]) / 도움 요청(빨간 배너, [대상자 확인])
      안전 응답("괜찮다고 응답했습니다.") / 응답 시간 만료(노란 배너)
      각 배너 오른쪽 [X]로 닫기
  - 오른쪽 아래 "새 알림" 토스트: 건수 요약, 클릭하면 알림 배너 목록으로 이동
  - 오른쪽 위: 실시간 연결 상태(연결됨 / 연결 중 / 재연결 중)와 [새로고침]

3-2. 등록 대상자 목록 (대시보드 아래쪽, 또는 사이드바 [대상자 관리])
  - 위험 점수 높은 순으로 자동 정렬 = 먼저 확인할 순서
  - 위쪽 필터 버튼 [전체] [위험] [주의] [안정]
  - 오른쪽 검색창 "이름, 주소, 전화번호 검색"
  - 각 줄: 대상자 이름·나이·주소, 전화번호(클릭 시 전화), 위험 단계, 현재 위험 점수, 최근 알림 응답, [상세보기]
  - 도움 요청이 온 대상자는 이름 옆 [도움 요청] 배지 + [해결 완료] 버튼
      [해결 완료] 클릭 → 응답 칸이 "해결 완료"로 바뀌고 배너 정리
  - 표 아래: 표시 인원 수, 최근 갱신 시각

3-3. 대상자 등록 (대시보드·대상자 관리 화면 오른쪽 위 주황 [대상자 등록])
  - 입력: 이름, 생년월일, 전화번호(예: 01012345678), 가구 ID, 주소, 상세 주소, 담당자 메모
  - 아래 [대상자 등록] 클릭 → "대상자를 등록했습니다." / 폼 오른쪽 위 [닫기]로 취소
  - 가구 ID는 이미 등록된 가구여야 연결됨
  ※ 시연 중에는 실제 데이터가 생기므로 폼만 열어 보여 주고 [닫기] 권장

3-4. 대상자 상세 (목록의 [상세보기], 배너의 [상세보기]/[대상자 확인])
  - 현재 상태: 위험 단계 배지, 위험 점수, 상태 갱신 시각
  - 연락 및 알림 응답: 전화번호, 최근 응답, 응답 시각
  - 일별 위험 점수 추이: 최근 7일 그래프
  - 알림 및 응답 이력: 조회 기간 [최근 7일/30일/90일], [새로고침], 아래 [이력 더 보기]
      배너에서 들어오면 해당 알림이 강조되고 그 위치로 자동 스크롤
  - 왼쪽 위 [← 대상자 목록]으로 돌아가기

3-5. 최근 알림 (왼쪽 사이드바 [최근 알림])
  - 위험 감지 / 도움 요청 / 안전 응답 / 응답 시간 만료 / 안부 확인 알림을 최근 순으로 표시
  - 해결된 건은 "· 해결 완료" 표시, 각 건의 [상세보기]로 대상자 상세 이동

3-6. 로그아웃
  - 왼쪽 사이드바 맨 아래 [로그아웃]


--------------------------------------------------------------
 4. 주의사항 / 문제 해결
--------------------------------------------------------------
- 같은 브라우저에서 다른 역할로 들어가면 "OO 계정으로 로그인되어 있어요" 화면이 뜬다.
  [로그아웃] 후 다시 로그인하거나, 처음부터 브라우저를 나눠서 쓴다.
- 담당자 화면에서 실시간으로 도착하는 알림 배너는 대상자 01(시연 대상자)만 대상이다.
  나머지 29명은 시연용 고정 점수로 표시된다. (대상자 03 · 06은 주의, 나머지는 안정)
- 푸시 알림이 안 오면: 대상자 화면 "안심 알림"이 켜져 있는지, Windows 알림 설정과
  방해 금지 모드가 꺼져 있는지 확인한다. 푸시가 안 와도 대상자 화면 하단의 응답 창은 뜬다.
- 담당자 화면 오른쪽 위가 "재연결 중"이면 실시간 알림이 늦게 오므로 페이지를 새로고침한다.
- 시뮬레이터는 EC2-A의 simulator 컨테이너가 꺼져 있으면 502가 난다.
  기동 방법은 루트의 깃플로우및실행안내.md "2-3. EC2-A에서 Docker로 실행" 참고.
- 재시연할 때는 대상자 01의 도움 요청을 [해결 완료]로 정리하고, 시뮬레이터 페이지를 새로고침한 뒤
  [▶ 실시간 실행]부터 다시 진행한다. ([↺ 처음부터]는 위쪽 평소 패턴 재생만 되감는다.)
